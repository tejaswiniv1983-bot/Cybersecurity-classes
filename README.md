# 🔐 Cybersecurity 13-Day Program

## About
This repository documents my learning journey through a 13-day Cybersecurity training program, including day-wise notes, security concepts, and practical exercises.

## Topics Covered
- Day 01: Introduction to Cybersecurity
- Day 02: Networking Basics
- Day 03: Linux Basics
- Day 04: Web Security Basics
- Day 05: Passwords and Authentication
- Day 06: Cryptography
- Day 07: Phishing and Social Engineering
- Day 08: Vulnerability Assessment
- Day 09: Ethical Hacking Basics
- Day 10: Security Tools and Labs
- Day 11: Malware and Incident Response
- Day 12: Digital Forensics Basics
- Day 13: Cybersecurity Project

## Learning Objectives
- Understand cybersecurity fundamentals.
- Learn basic networking and Linux commands.
- Recognize common cyber threats.
- Understand security tools and defensive techniques.
- Practice ethical and authorized security testing.
- Document learning activities using GitHub.
