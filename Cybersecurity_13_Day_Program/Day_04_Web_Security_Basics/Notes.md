# Day 04 – Web Security Basics

## Objective
Understand common web security risks and basic prevention methods.

## Topics Covered
- Websites and web applications
- Client-server communication
- Common web vulnerabilities
- Input validation
- Authentication and authorization
- Secure HTTPS communication

## Key Learnings
Web security protects websites, web applications, and user data from attacks.

- **SQL Injection:** Malicious input attempts to manipulate database queries.
- **Cross-Site Scripting (XSS):** Malicious scripts execute in a user's browser.
- **Authentication:** Verifies a user's identity.
- **Authorization:** Determines what an authenticated user can access.
- **Input Validation:** Checks user input before processing it.

## Prevention
Use parameterized queries, validate inputs, apply access controls, and keep software updated.
