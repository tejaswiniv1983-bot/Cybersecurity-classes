# Day 02 – Networking Basics

## Objective
To understand the fundamentals of computer networking and how devices communicate.

## Topics Covered
- Introduction to Computer Networks
- LAN, WAN, and MAN
- IP Addresses
- DNS (Domain Name System)
- HTTP and HTTPS
- TCP and UDP

## Key Learnings

### 1. Computer Network
A computer network connects devices to exchange information and share resources.

### 2. Types of Networks
- **LAN:** Local Area Network, used in homes, offices, and colleges.
- **WAN:** Wide Area Network, connects devices over large geographical areas.
- **MAN:** Metropolitan Area Network, covers a city or large campus area.

### 3. IP Address
An IP address identifies a device on a network.

### 4. DNS
DNS translates domain names into IP addresses so browsers can locate servers.

### 5. HTTP and HTTPS
These protocols allow browsers and web servers to communicate. HTTPS protects communication using encryption.

### 6. TCP and UDP
- **TCP:** Provides reliable, ordered delivery of data.
- **UDP:** Sends data with lower overhead but does not guarantee delivery.
