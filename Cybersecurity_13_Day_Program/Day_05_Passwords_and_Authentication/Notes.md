# Day 05 – Passwords and Authentication

## Objective
Understand password security and methods of verifying user identities.

## Topics Covered
- Strong passwords
- Password managers
- Multi-factor authentication (MFA)
- Authentication methods
- Password hashing
- Account security

## Key Learnings
- **Strong Password:** A long, unique password that is difficult to guess.
- **MFA:** Uses two or more types of verification.
- **Password Manager:** Stores passwords securely.
- **Hashing:** Converts data into a fixed-length digest.
- **Salting:** Adds random data before password hashing to make attacks harder.

## Security Practices
- Never reuse important passwords.
- Enable MFA wherever possible.
- Never share passwords or verification codes.
- Use trusted password managers.
- Avoid storing passwords in plain text.

Record any password-security exercises completed in class.

## Conclusion
Learned how secure passwords and authentication reduce unauthorized access.
