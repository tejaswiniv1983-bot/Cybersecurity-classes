# Day 10 – Security Tools and Labs

## Objective
Understand cybersecurity tools and their safe use in authorized environments.

## Topics Covered
- Network analysis
- Packet inspection
- Web security testing
- Vulnerability scanning
- Linux security utilities
- Lab safety

## Examples of Tools
- **Wireshark:** Analyzes network traffic.
- **Nmap:** Discovers hosts and services on authorized networks.
- **Burp Suite:** Supports web application security testing.
- **Nessus:** Performs vulnerability assessments.
- **Linux Utilities:** Help inspect files, permissions, processes, and network settings.

## Key Learnings
Security tools help professionals investigate networks, identify weaknesses, and understand potential security issues. Results should be verified rather than assumed to be correct.

## Practical Work
For each tool used, record its purpose, the authorized lab environment, commands or steps used, and observations.

## Conclusion
Learned about common security tools and the importance of using them responsibly.
