# Day 11 – Malware and Incident Response

## Objective
Understand malware types and the basic process of responding to security incidents.

## Topics Covered
- Viruses and worms
- Trojan horses
- Ransomware
- Spyware
- Malware prevention
- Incident response

## Key Learnings
Malware is software designed to perform harmful or unauthorized activities.

- **Virus:** Attaches to files or programs and can spread when they run.
- **Worm:** Can spread between systems.
- **Trojan:** Disguises itself as legitimate software.
- **Ransomware:** Locks or encrypts data to demand payment.
- **Spyware:** Secretly collects information.

## Incident Response Stages
1. Preparation.
2. Detection and analysis.
3. Containment.
4. Eradication.
5. Recovery.
6. Lessons learned.

## Prevention
Keep systems updated, use reputable security software, back up important files, and avoid suspicious downloads.

## Practical Work
Document any incident-response or malware-awareness simulation performed in class. Do not run unknown malware on a personal device.

## Conclusion
Learned common malware types and the basic steps used to manage security incidents.
